# Intelligent Accident Detection System using CNN and LSTM

## 📌 Project Overview

The **Intelligent Accident Detection System** is an AI-based accident detection application designed to identify road accidents from video data.

The system uses **Computer Vision, Convolutional Neural Networks (CNN), and Long Short-Term Memory (LSTM)** techniques to analyze video information and identify accident-related events.

The application provides a graphical user interface that allows users to select video files and process them for accident detection.

## 🎯 Objectives

- Detect accidents from video footage using Artificial Intelligence.
- Analyze visual information from road traffic videos.
- Reduce the dependency on continuous manual CCTV monitoring.
- Provide an automated accident detection mechanism.
- Demonstrate the use of deep learning and computer vision for road safety.
